Autenticacion y Crear Cuentas

Creando un sistema de Autenticacion robusto

-- Hoy en día no hay solo sitio web que sea utilizado por miles de usuarios que no tenga autenticación y registro de usuarios.
-- Sitios de bancos, tiendas virtuales, aplicaciones de celular, todos tienen algún sistema de autenticación integrado.
-- La autenticación nos permitirá identificar a nuestros usuarios y darles ciertos accesos a su información.


Principios de autenticacion hay diferentes formas de autenticar a un usuario

-- Un Usuario se puede autenticar con algo que el recuerda (Email y Password)
-- Un Usuario se puede autenticar con un dispositivo físico (Mensaje SMS o alerta)
-- Un Usuario se puede autenticar con algo físico (Huella Digital, Voz o Cara

Algoritmo para crear Cuentas

-- Usuarios deberan ser unicos, usualmente para crear una cuenta se pide el e-mail del usuario. No puede haber e-mail duplicados
-- Los Password deben ser hasheados para no ponerlos en la base de datos
-- Una buena forma de evitar llenarte de usuarios es enviar un enlace de verificacion al e-mail y entonces el usuario debera realizar algina accion(como tarjeta de credito o numero de celular)
-- Una vez creada la cuenta y que se confirma puede usar la app

npm i bcrypt

Es una librería que sirve para encriptar (hashear) contraseñas de forma segura antes de guardarlas en la base de datos

ALGORITMO PARA INICIAR SESION

La primera comprobacion que debemos hacer es saber si el usuario existe o no
La segunda es comprobar si su cuenta fue confirmada
La ultima comprobacion es revisar si el password es correcto, en caso de que si lo sea el usuario se autentica

Algoritmo para restablecer un password

-Primer comprobacion es saber si el usuario existe
-Si el usuario existe se le envia el token 
- El token se envia por mail y el usuario debera visitar un enlace e ingresar ese token, si el token es valido le permitimos restablecer su password
